📸 Deploy A6000 Photography OS lên Web

Chuyển app của bạn thành website online, tự động cập nhật mỗi khi bạn chỉnh sửa!

✅ Bạn có gì trong tay:
  • Folder a6000-pwa chứa app hoàn chỉnh
  • Progressive Web App với offline support
  • Auto-update khi có phiên bản mới
  • Có thể cài như app trên điện thoại

🚀 Chọn 1 trong 3 cách deploy (Đề xuất: GitHub Pages)

1. GitHub Pages MIỄN PHÍ ĐỀ XUẤT
✨ Tốt nhất cho long-term, dễ update, URL đẹp, 100% miễn phí
1 Tạo GitHub account (nếu chưa có)

Vào https://github.com/signup

2 Tạo repository mới
  • Vào https://github.com/new
  • Repository name: a6000-photography-os
  • Chọn Public
  • Click Create repository
3 Upload files lên GitHub

Cách A - Dùng Web (Dễ nhất):

  • Trong repository vừa tạo, click uploading an existing file
  • Kéo thả tất cả files trong folder a6000-pwa
  • Scroll xuống, click Commit changes

Cách B - Dùng Git command line:

cd a6000-pwa git init git add . git commit -m "Initial release" git branch -M main git remote add origin https://github.com/USERNAME/a6000-photography-os.git git push -u origin main

Thay USERNAME bằng tên GitHub của bạn

4 Bật GitHub Pages
  • Trong repository, vào Settings → Pages
  • Source: Deploy from a branch
  • Branch: main / / (root)
  • Click Save
5 🎉 Xong! Truy cập app của bạn

URL: https://USERNAME.github.io/a6000-photography-os/

⏱ Đợi 2-3 phút cho lần deploy đầu tiên

✅ Cách update sau này:
  • Vào repository trên GitHub
  • Click vào file cần sửa (vd: index.html)
  • Click nút ✏️ Edit
  • Chỉnh sửa nội dung
  • Scroll xuống, click Commit changes
  • Đợi 1-2 phút → Website tự động cập nhật!
  • User mở app sẽ thấy thông báo có bản cập nhật mới
2. Netlify Drop DỄ NHẤT
⚡ Deploy trong 30 giây, không cần account, URL ngẫu nhiên
1 Vào Netlify Drop

https://app.netlify.com/drop

2 Kéo thả folder

Kéo toàn bộ folder a6000-pwa vào trang web

3 🎉 Xong!

Bạn sẽ nhận được URL kiểu: https://random-name-123.netlify.app

⚠️ Lưu ý:
  • URL là random (có thể đổi nếu tạo account Netlify)
  • Để update: phải upload lại toàn bộ folder
  • Tốt cho demo nhanh, không tốt cho long-term
3. Vercel NHANH
🚄 Deploy siêu nhanh, URL đẹp, cần GitHub account
1 Upload code lên GitHub

Làm theo bước 1-3 của phương pháp GitHub Pages ở trên

2 Tạo Vercel account

Vào https://vercel.com/signup

Đăng nhập bằng GitHub account

3 Import repository
  • Click Add New Project
  • Chọn repository a6000-photography-os
  • Click Deploy
4 🎉 Xong!

URL: https://a6000-photography-os.vercel.app

Mỗi lần bạn push code mới lên GitHub, Vercel tự động deploy!

📱 Cài App lên Điện Thoại

iPhone (Safari):
  1. Mở website bằng Safari
  2. Nhấn nút Share (hình mũi tên chỉ lên)
  3. Chọn Add to Home Screen
  4. Nhấn Add
Android (Chrome):
  1. Mở website bằng Chrome
  2. Nhấn menu ⋮ (3 chấm)
  3. Chọn Install App hoặc Add to Home screen
  4. Nhấn Install
✅ Sau khi cài:
  • App xuất hiện như app bình thường trên màn hình
  • Mở app = full screen (không có thanh địa chỉ browser)
  • Hoạt động offline (sau lần mở đầu tiên)
  • Tự động thông báo khi có bản update mới

🔄 Cách Update Nội Dung

1 Chỉnh sửa file

Sửa trực tiếp trên GitHub (nút ✏️) hoặc edit local rồi push lên

2 Update version number

Mở file version.json, tăng số version:

{ "version": "v1.0.1", ← Tăng số này "buildDate": "2026-10-07", "changelog": [ "Added new video scenario", "Fixed cafe preset" ] }
3 Commit changes

Sau 1-2 phút, website tự động cập nhật

4 🎉 User thấy thông báo update

Khi user mở app, sẽ thấy banner thông báo có bản mới, tap để reload!

🛠 Troubleshooting

❓ Website không hiển thị?
  • Đợi 2-3 phút cho lần deploy đầu
  • Check GitHub Pages settings đã bật chưa
  • URL phải là: https://USERNAME.github.io/REPO-NAME/
❓ App không update?
  • Đã tăng version number trong version.json chưa?
  • Hard refresh: Ctrl+Shift+R (desktop) hoặc xóa cache
  • Service worker cần 1-2 phút để phát hiện update
❓ Icons không hiện?
  • Đảm bảo file icon-192.png và icon-512.png đã upload
  • Check file manifest.json có paths đúng
  • Thử re-deploy
