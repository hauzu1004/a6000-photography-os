🎥 A6000 VIDEO OS
Sony A6000 + 50mm F1.8 OSS. A practical Full HD workflow designed around what this camera actually supports.
25p → 1/50s → choose aperture → control ISO → choose focus → lock/choose WB → record
50p → 1/100s → use when you want smoother motion / 2× slow motion on a 25p timeline
A6000 is a Full HD camera internally. Do not build this workflow around internal 4K. In PAL, XAVC S was enabled by firmware 2.00; Sony's current support page lists firmware 3.21. For XAVC S, use an SDXC Class 10 or faster card and format it in-camera after the required firmware update.
⚡ IF YOU REMEMBER ONLY 5 THINGS
1. 25p → start around 1/50s.
2. 50p → start around 1/100s.
3. f/2.8 is usually a safer video default than always shooting at f/1.8.
4. AF-C for people moving; MF/AF-S for controlled static shots.
5. Lock WB for a controlled sequence when color consistency matters.

⚙️ HOW TO SET THE CAMERA
1. Select Movie mode: Mode Dial → Movie.
2. Choose exposure mode: MENU → Camera Settings → Movie → choose M / Manual Exposure for the controlled base workflow. Sony confirms Movie mode offers Program Auto, Aperture Priority, Shutter Priority and Manual Exposure.
3. Set file format: MENU → Camera Settings → File Format → XAVC S / XAVC S HD where available after firmware update.
4. Set frame rate / quality: MENU → Camera Settings → Record Setting → 25p 50M or 50p 50M in PAL.
5. Set shutter: In M mode, use the control wheel for shutter speed. Start 1/50 for 25p or 1/100 for 50p.
6. Set aperture: In M mode, use the control dial for aperture.
7. Set ISO: ISO AUTO for changing light; manual ISO for a controlled sequence.
8. Record: press the MOVIE button to start/stop.

🔍 FOCUS FOR VIDEO
STATIC OBJECT
MF or AF-S. Coffee, product, decor, wall art, tripod shots.
MOVING PERSON
AF-C. Use a suitable Focus Area; avoid relying on features from newer Sony bodies that A6000 does not have.
CINEMATIC FOCUS CHANGE
Use AF Drive Speed → Slow for smoother autofocus changes. For repeatable focus pulls, MF is more controllable.
FAST ACTION
AF Drive Speed → Fast and AF Track Duration → High when the subject is changing position quickly.
LOW CONTRAST / DARK
If AF hunts, give the camera a stronger edge/detail to lock onto, use AF-S, or switch to MF.
f/1.8 WARNING
With 50mm on APS-C (~75mm equivalent), f/1.8 can make focus mistakes obvious. f/2.8 is often a better working default.
🎨 COLOR / PICTURE PROFILE
Easy / minimal grading: Picture Profile OFF as the starting point.
Intermediate: A6000 factory Picture Profiles include PP5 (Cine1) and PP6 (Cine2). Use only when you have a reason to grade.
Advanced: PP7 uses S-Log2. Sony describes S-Log2 as a profile intended for post-processing; high ISO/noise in shadows is a real concern.
Rule: A “cinematic” image comes from exposure, light, movement, composition and color work—not simply turning on S-Log2.
⚪ WHITE BALANCE
Auto WB → safest beginner default when light changes.
Daylight → consistent outdoor color.
Cloudy → slightly warmer outdoor starting point.
Incandescent → useful for tungsten-heavy indoor scenes.
For a controlled sequence, lock WB so the camera does not visibly shift color between shots. For mixed daylight + artificial light, Auto WB is the practical starting point.
📊 EXPOSURE TOOLS
Histogram → check overall exposure.
Zebra → useful as a highlight warning; A6000 provides 70–100 and 100+ options.
Manual exposure → best for consistent sequences.
Avoid using a fixed EV number as a video recipe. In M + ISO Auto, control exposure primarily with ISO while keeping shutter/aperture where you need them.
🧍 STABILIZATION / 50MM STRATEGY
Handheld: SteadyShot ON. The camera body does not provide sensor-shift stabilization; stabilization with this lens comes from the lens OSS.
Tripod: SteadyShot OFF when appropriate.
Walking: 50mm APS-C ≈ 75mm equivalent, so handheld walking shots will look more shaky than a wide lens. Prefer short static clips, support, or very controlled movement.
Do not fake a gimbal: Use slow, simple camera moves. A clean locked shot is often better than a shaky “cinematic” move.
🎙 AUDIO — IMPORTANT FOR A6000
Important correction: The A6000 does NOT have a normal 3.5 mm microphone jack. Sony states that an external microphone can be connected through the Multi Interface Shoe; Sony specifically lists the ECM-XYST1M as a compatible microphone. The camera also has a built-in stereo microphone.
INTERNAL MIC
Use for ambience: cafe, street, rain, nature. Keep fingers and handling noise away from the mic openings.
EXTERNAL MIC
Use a compatible microphone on the Multi Interface Shoe. A Sony ECM-XYST1M is one documented example.
AUDIO REC LEVEL
Set a sensible level and test before an important take. Do not rely on fixing badly clipped audio later.
WIND
Use a physical windscreen. Do not assume camera wind-noise reduction will replace a proper windshield on an external mic.

🎥 SHOOTING TECHNIQUES
LOCKED SHOT
Best default. Stabilize, start recording, hold the frame 5–10s, stop smoothly.
SLOW PAN
Use support if possible. Start still → move slowly → finish still.
PUSH-IN
Move your body slowly toward the subject. With 75mm-equivalent framing, tiny camera movements are visible.
FOLLOW SUBJECT
AF-C or pre-focused MF. Keep movement of the camera simpler than the movement of the subject.
RACK FOCUS
For repeatable results, use MF. Pre-focus, then turn the focus ring smoothly. Record several takes.
5–10 SECOND RULE
Let the shot breathe before and after the key action. More usable in editing.
🧰 CONVENIENT CAMERA SETTINGS
AF Drive Speed → Normal: safe default. Use Slow for smoother focus changes; Fast for active scenes.
AF Track Duration → Normal: safe default for crowded scenes. Use High for faster moving subjects.
MOVIE Button → Movie Mode Only: useful if you often press the MOVIE button by accident outside Movie mode.
Grid Line → Rule of thirds: useful for beginner composition and leveling.
SteadyShot: ON handheld / OFF on tripod when appropriate.
Auto Slow Shutter: OFF for a controlled M-mode 25p workflow. When enabled in supported auto modes, Sony can slow shutter in dark scenes; that can reduce noise but introduces more motion blur.
🆘 TROUBLESHOOTING
Video looks choppy: shutter may be too fast or camera movement too abrupt. Return toward 1/50 at 25p and simplify movement.
Video is too blurry: shutter may be too slow for the subject, or focus is missing. Check shutter, then focus.
Focus hunts: use stronger contrast, AF-S, smaller aperture like f/2.8, or MF.
Image is noisy: add light first; then open aperture; then raise ISO. Do not solve every low-light problem by making shutter faster.
Color changes between clips: lock WB for controlled sequences.
Camera shakes: remember 50mm ≈ 75mm equivalent; use support and shorter, simpler moves.

🧭 VIDEO LIMITATIONS — KNOW THEM
Internal recording is Full HD, not internal 4K.
50mm on APS-C is about 75mm equivalent: great for detail/portrait B-roll, weak for self-vlogging, tiny rooms and wide establishing shots.
A6000 has no modern touch-to-focus / real-time tracking workflow. Do not expect newer Sony AF behavior.

The A6000 is capable of very nice Full HD footage when light, composition, movement and audio are controlled, but it is not a modern 4K hybrid video body.

🏠 Whole aquarium / Toàn bộ bể
A → f/4–5.6 → ISO AUTO 100–6400 → AF-S → Flexible Spot / Wide → Auto WB → Flash OFF
Use f/4–5.6 so the tank, plants and hardscape have more usable depth than at f/1.8. With 50mm on APS-C (~75mm equivalent), step back as needed to fit the tank.
🐟 Swimming fish / Cá đang bơi
S → 1/250 s start → 1/500 s for faster fish → ISO AUTO 100–6400 → AF-C → Flexible Spot → Flash OFF
Start at 1/250. If the fish still shows motion blur, move to 1/320 or 1/500. Do not open to f/1.8 automatically just because the tank is dark; first balance shutter, ISO and the available aquarium light.
🌿 Aquatic plants / rocks / details
A → f/2.8–4 → ISO AUTO → AF-S → Flexible Spot → Flash OFF
Good for a single plant, moss, rock texture, bubbles or a fish resting near a plant. f/2.8–4 gives more focus margin than f/1.8 while still giving background separation.
🌙 Illuminated fish / dark background
M → f/2–2.8 → 1/160–1/250 s → ISO 800–1600 start → AF-S → Flexible Spot → Auto WB → Flash OFF
Treat the aquarium light as the key light. Let darker areas remain dark. Lower ISO if highlights clip; raise ISO if the fish is too dark. This is the aquarium version of the Night — Lit Subject / Dark Sky style.
🪟 GLASS / REFLECTION CONTROL
1) Turn off or dim room lights behind you. 2) Move the lens close to the glass without touching it. 3) Change your angle slightly if a reflection remains. 4) Avoid flash — it commonly produces a strong reflection on the glass. 5) Clean the outside of the glass before shooting.
🎯 FOCUS TIPS
Static plant/rock → AF-S or MF. Moving fish → AF-C. If AF hunts in dark water, place Flexible Spot on a lit edge/detail. If it still cannot lock, use MF and pre-focus on the fish's swimming plane.

🎯 The visual goal
Make the illuminated subject the visual anchor. Keep large areas of the sky/background genuinely dark. Do not try to make the entire frame look like daytime.
⚡ QUICK SETUP — START HERE

🌌 COMPOSITION — THIS IS THE SECRET
🌸 Flower + Dark Sky
FRAME Let the flowers occupy only roughly 20–40% of the frame; leave generous dark negative space.
TIP Use the 50mm's relatively narrow field of view to isolate one section of the tree instead of trying to show the whole tree.
🌳 Tree + Street Light
LOOK FOR The part of the tree that naturally catches the lamp/store light. Exclude unrelated bright areas.
TIP Try placing the lit tree on one side of the frame and keep most of the opposite side dark.
💡 Neon / Shop Light + Plant
LOOK FOR A colored light source spilling onto leaves or flowers.
TIP Start with Auto WB. Later try around 4000–5000K if you deliberately want a cooler night feel.
🌧 Wet Night + Reflection
LOOK FOR Wet pavement, puddles and reflected lamps/neon. Keep one clear lit subject as the anchor.
TIP Lower the camera and use the reflection as a second visual layer rather than filling the frame with the road.
🧠 REMEMBER THIS
The style comes from contrast, not from a special “night mode”. Find a real light source, put the subject inside that light, expose for the subject, and let the surrounding darkness remain dark.
50mm limitation: On A6000 the lens is about 75mm equivalent, so step back when you need more context. Do not expect a wide environmental view.

🌤 WEATHER / LIGHT CONDITIONS
Weather and light are different. Weather is sunny/rainy. Light is harsh/soft/golden/blue. Same weather can produce different light. This guide helps you adapt your presets to current conditions.
WHAT SHOULD I SHOOT TODAY?
☀️ Sunny: Look for shadows, contrast, silhouettes, architecture
☁️ Overcast: Look for people, colors, greenery, soft portraits
🌧 Before rain: Look for dramatic clouds, umbrellas, reflections
🌧 Rain: Look for wet roads, reflections, umbrellas, droplets
🌅 Golden hour: Look for backlight, silhouettes, warm portraits
🔵 Blue hour: Look for buildings + lights + blue sky
🌙 Night: Look for neon, streetlights, reflections, light/shadow
☀️ BRIGHT SUN / CLEAR SKY
WHAT CHANGES

Harsh shadows, strong highlights, high contrast. Risk of blown highlights. Shadows become creative elements.

BEST THINGS TO SHOOT
  • Hard shadow patterns on walls/ground
  • Architecture with strong light/shadow
  • Trees against bright sky (silhouettes)
  • People crossing sunlight/shadow boundaries
  • Strong graphic compositions
BEST STARTING PRESETS
🏙 Street MR3
✈️ Travel MR3
🌅 Backlight MR2
QUICK ADJUSTMENT

MR3 → f/4–8 for general outdoor → EV 0 to -0.7 if highlights are important (bright sky, reflections) → ISO AUTO 100–1600 or 100–3200 depending on shutter needs → shoot

WHY IT WORKS

Bright sun creates strong directionality. Negative EV preserves sky and bright areas. Stopped-down aperture (f/4–8) increases depth and reduces lens flare.

COMPOSITION IDEA

Position subjects at shadow/light boundaries. Use shadows as leading lines or frames.

WATCH OUT FOR

Do NOT blindly set EV -0.7. Check your frame. If the subject is in shadow and sky is bright, you may need EV +0.3 to +1.0 to lift the subject instead.

🌤 SOFT SUN / LIGHT CLOUD
WHAT CHANGES

Softer than harsh noon light, but still directional. Flattering for people. Good balance between sky and subject.

BEST THINGS TO SHOOT
  • Portraits (outdoor, environmental)
  • Trees and greenery
  • Street scenes
  • Outdoor cafe
BEST STARTING PRESETS
👤 Portrait MR2
🏙 Street MR3
☕ Cafe MR1
QUICK ADJUSTMENT

MR2 for person → f/1.8–4 depending on isolation vs detail → EV 0 to -0.3 → ISO AUTO → shoot

WHY IT WORKS

Soft sun provides direction without harsh shadows. Good for portraits because light wraps naturally around faces.

COMPOSITION IDEA

Use f/1.8–2.8 to isolate subject from background. Position subject at 45° from light source.

WATCH OUT FOR

Light changes quickly as clouds move. Check exposure as clouds pass over the sun.

☁️ OVERCAST
WHAT CHANGES

Light is diffused. Softer shadows. Lower contrast. Colors can feel muted. Sky often becomes a large bright area. The cloud cover acts as a massive natural softbox.

BEST THINGS TO SHOOT
  • Portraits (flattering skin tones, no squinting)
  • Greenery (rich midtones)
  • Urban scenes
  • Minimalist compositions
  • Pastel colors
  • Reflective surfaces
  • People under umbrellas (if rain approaching)
BEST STARTING PRESETS
👤 Portrait MR2
🏙 Street MR3
☕ Cafe MR1
✈️ Travel MR3
QUICK ADJUSTMENT

Portrait → MR2 → f/1.8–2.8 | Outdoor general → MR3 → f/4–5.6 | Cafe → MR1 → f/1.8–2.8 | EV 0 to -0.3 as starting point, adjust based on sky brightness → ISO AUTO

WHY IT WORKS

Soft diffused light eliminates harsh shadows and blown highlights. Consistent light throughout the day means no golden hour time constraints. Wide aperture (f/1.8–2.8) for portraits creates separation; stopped down (f/4–5.6) for scenes preserves detail.

COMPOSITION IDEA

Add directionality with a reflector if light feels flat. Consider black and white to emphasize lines and textures. Shoot wide open (f/1.8–2.8) to separate subject from background in street work.

WATCH OUT FOR

Bright overcast sky can fool meter. If sky dominates the frame, use EV -0.3 to -0.7 to prevent subject from going too dark.

🌧 BEFORE RAIN / STORMY SKY
WHAT CHANGES

Dramatic clouds. Darker ambient light. Directional breaks in light. Stronger mood. Saturated colors. Dramatic sky/background separation.

BEST THINGS TO SHOOT
  • Clouds + buildings (dramatic skyline)
  • Trees against dramatic sky
  • Lone person in darkening scene
  • Umbrellas before rain
  • Dark foreground + bright horizon
  • Reflections beginning to appear
BEST STARTING PRESETS
🏙 Street MR3
✈️ Travel MR3
👤 Portrait MR2
QUICK ADJUSTMENT

MR3 as base → f/4–5.6 for landscapes/scenes → f/1.8–2.8 for isolated details → ISO AUTO → EV 0 to -0.7 depending on sky (preserve dramatic clouds) → do not force high ISO if light is still sufficient

WHY IT WORKS

Stormy skies create visual drama. Negative EV preserves cloud detail without turning them into flat white. The darker ambient light creates stronger mood and color saturation.

COMPOSITION IDEA

Expose for dramatic skies but keep foreground from going completely black. If foreground is too dark, use EV +0.3 to +0.7 or position subject in a brighter area.

WATCH OUT FOR

Light changes very quickly before rain. Check shutter speed as ambient light drops. Watch histogram to avoid turning scene into pure silhouette unless that is your intent.

🌧 RAIN
WHAT CHANGES

Wet streets become reflective surfaces. Puddles mirror lights and subjects. Raindrops visible with backlighting. Lower ambient light. People move differently (umbrellas, rushing). Wet surfaces + city lights often produce HDR-looking photos.

BEST THINGS TO SHOOT
  • Umbrellas (color, shape, storytelling)
  • Reflections on wet roads
  • Water drops (on windows, leaves, surfaces)
  • People running or walking in rain
  • Rain through backlight (streetlights, shop windows)
  • Cafe windows with rain outside
  • Lights reflected on wet surfaces
  • Neon signs + wet pavement
BEST STARTING PRESETS
🏙 Street MR3
☕ Cafe MR1
🏃 Action (S mode)
QUICK ADJUSTMENT

You are outside in rain: For moving people → S mode → 1/320–1/500 → ISO AUTO 100–6400 → AF-C → Zone | For static rain details → A mode → f/1.8–2.8 → AF-S → Flexible Spot | You are sheltered/inside cafe: MR1 → f/1.8–2.8 → ISO AUTO → shoot through window

WHY IT WORKS

Raindrops are invisible when front-lit but glow with backlighting. Fast shutter freezes rain and umbrella details. Wide aperture (f/1.8–2.8) isolates subject from busy rain background.

COMPOSITION IDEA

Position yourself so streetlights or bright sources are behind falling rain. Use slow shutter (1/15–1/2s) for motion streaks, or fast shutter (1/250–1/1000s) to freeze drops.

WATCH OUT FOR — GEAR PROTECTION

The A6000 + Sony 50mm F1.8 OSS is NOT weather-sealed. Use a rain cover, plastic bag protection, or umbrella. Keep water away from openings and contacts. Wipe moisture promptly. Do not encourage deliberate water exposure.

🌅 GOLDEN HOUR
WHAT CHANGES

Warm light (reds, oranges, yellows). Long shadows. Softer directional light. Backlight and rim light opportunities. Low-angle sunlight creates dimension. Occurs ~20-60 minutes after sunrise and before sunset.

BEST THINGS TO SHOOT
  • Portraits (warm, flattering light)
  • Trees (long shadows, backlighting)
  • Silhouettes
  • Buildings (warm glow on facades)
  • People walking (long shadow play)
  • Cafe outdoor seating
BEST STARTING PRESETS
👤 Portrait MR2
🏙 Street MR3

💡 UNDERSTANDING EV (EXPOSURE COMPENSATION)
EV is a CORRECTION based on what the camera measures. It is NOT a fixed weather setting. Your camera's meter aims for middle grey. EV tells it "make it darker (negative) or brighter (positive) than what you measured."
WHEN TO USE NEGATIVE EV (-0.3 to -0.7 or more)
  • Bright sky dominates the frame (camera tries to darken it, sky blows out)
  • Bright neon signs at night (preserve sign detail)
  • Snow or very bright scenes (camera underexposes them thinking they are too bright)
  • Dramatic clouds you want to preserve (before rain, stormy sky)
  • Silhouettes (intentionally darkening the subject)
WHEN TO USE POSITIVE EV (+0.3 to +1.0 or more)
  • Subject in shadow, bright sky behind (backlight—camera exposes for bright sky, subject goes too dark)
  • Dark alley with one dim streetlight (camera thinks scene is brighter than it is)
  • Very dark scenes where you want to lift subject brightness
  • Predominantly dark subjects on bright backgrounds
WHEN TO USE EV 0 (NO COMPENSATION)
  • Normal balanced scenes
  • When the camera's meter is correctly exposing your subject
  • Starting point for any new scene—adjust after checking the frame
HOW TO USE EV CORRECTLY

1. Take a test shot at EV 0 → 2. Check the image on screen → 3. Is the important part too bright? Use negative EV (-0.3, -0.7, etc.) → 4. Is the important part too dark? Use positive EV (+0.3, +0.7, etc.) → 5. Shoot again → 6. Repeat until correct

MOST IMPORTANT RULE

Always check YOUR frame. Bright sun does not automatically mean EV -0.7. Overcast does not automatically mean EV -0.3. Night does not automatically mean EV -0.7. The EV ranges in this guide are STARTING SUGGESTIONS based on common situations. YOUR specific frame determines the final EV value.

⚠️ IMPORTANT TERMINOLOGY
Focus Mode vs AF/MF Control:
• Focus Mode: A6000 options are Single-shot AF (AF-S), Automatic AF, Continuous AF (AF-C), DMF, and Manual Focus (MF)
• AF/MF Control: Switches between Auto Focus (AF) ↔ Manual Focus (MF) only; it does not select AF-S/AF-C

Sony A6000 menus use 'Focus Mode' (not 'AF Mode'). Match these exact names when navigating.
